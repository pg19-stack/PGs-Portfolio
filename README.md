# PG's Portfolio

**Pulkit Garg** | Strategy & Transformation

A personal portfolio showcasing enterprise strategy, AI value creation, and board-ready storytelling work.

## Live Site

Visit: [pg19-stack.github.io/PGs-Portfolio](https://pg19-stack.github.io/PGs-Portfolio)

## What's Inside

- **Case Studies** - Five photo cards; each opens the full case study in place
- **Capabilities** - Four pillars, how I work, and the toolkit I bring on day one
- **90-Day Impact Plan** - How I deliver value in the first 90 days
- **About** - Career timeline, experience highlights, awards and education

See [`REMAKE_REPORT.md`](REMAKE_REPORT.md) for the redesign checklist and photo credits.

## Setup

No build tools required. This is a static site.

```bash
# Clone the repo
git clone https://github.com/pg19-stack/PGs-Portfolio.git

# Open locally
open index.html
```

## Adding Your Photo

Replace `photo.jpg` in the root directory with your professional headshot. The site includes a fallback "PG" monogram if no photo is present.
